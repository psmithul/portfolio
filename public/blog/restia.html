Restia

I wanted my project files, tasks and study notes in one place. Restia is the tool I built for that.

By Mithul Sourav20 July 20262 min read

On this page

  1. Workspace and model choices
  2. Calendar and project planning
  3. Self-hosting and collaboration

I wanted to open a project and find the files, tasks and decisions I’d left there. I tried a few versions of the interface before settling on a board and documents for each project, with chat and study tools alongside them.

Workspace and model choices

I put decisions and documents inside the project so I could find them again after a chat ended. I kept the model choice in chat. That way I can switch between a local model and a hosted one from the same project.

Calendar and project planning

The board keeps track of work that needs to move through stages. The calendar is where I put work tied to a date or time, such as a test slot or a review. In this example, the calibration and review are calendar events, while the preparation and analysis stay on the project board.

Self-hosting and collaboration

The files and database live on the owner’s installation. When I added sharing between installations, I gave owners a choice between letting someone view a project and letting them edit it.
