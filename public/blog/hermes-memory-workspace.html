Hermes Memory Workspace

How I used an Obsidian vault for daily notes, project context, and handoffs between assistants.

By Mithul Sourav15 June 20262 min read

On this page

  1. Daily notes and project context
  2. Specialist profiles and handoffs

I made an Obsidian workspace to keep project context usable between sessions and specialist assistants. I used Markdown so I could read and edit the same files the assistant worked from.

Daily notes and project context

I used daily notes for recent work and decisions and living notes for background that still matters when someone returns to the project. I worked through where each update belonged. A temporary detail could stay in the day’s record, while a decision that changes the project could go into its living note.

I used the daily record to answer what happened and the living note to answer what someone needs to know now. A decision can appear in the day it was made, but I keep the current decision with the project so it can be found without reading the whole timeline.

Specialist profiles and handoffs

I removed 89 duplicated skill copies from nine specialist profiles. Seeing the same instructions in several places helped me decide what belonged in a specialist’s role, a shared procedure, or a project note.

I used a profile registry to describe each role and a task queue to record who had the work and where they stopped. Keeping the handoff with the task gave each progress update one place to live.

The duplicate count gave me a concrete cleanup result. The registry can now describe the role while shared procedures have a single place to be edited. I kept the last action and the open question on the task itself, because those are the details the next person needs when taking over.
