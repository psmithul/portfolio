Brain Tumour Detection

Python · Machine learning · 2021

We built a CNN to answer one question for each MRI image. Does the image show a tumour? We prepared and augmented the scans, trained the model, and ran it on individual images. Our team placed second among more than 100 teams from the region at the 2022 NITK EngiConnect Project Expo.

Preprocessing and augmentation

The original notebook used a dataset with two folders. There were 155 images labelled tumour and 98 labelled no tumour. I removed exact duplicates before splitting the images for the run shown here. That left 160 images for training, 34 for validation, and 34 for testing. Dataset listing.

The Keras generator resizes the images to 224 × 224 and scales their pixel values. It applies zoom, shear, and horizontal flips during training so the CNN sees some variation in how the brain sits in the frame.

Training and testing

The CNN uses four convolutional layers, followed by a single output score. A score of 0.5 or higher assigns the tumour label. I selected the checkpoint using validation accuracy and evaluated it on the held-out images.

In this run, the model matched 26 of 34 test labels. It missed two images labelled tumour and flagged six images labelled no tumour. The split is by image because the dataset supplies no patient identifiers. The project has no clinical validation.

Run the detector

The notebook downloads the project dataset, displays a sample from each class, trains the CNN, and scores a held-out image. The ZIP includes the Python scripts and an optional local Streamlit demo.
