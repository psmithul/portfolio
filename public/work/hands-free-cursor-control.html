Hands-free Cursor Control

Python · Computer vision · October 2022

I built a Python prototype to move the cursor without a mouse. I tried pointing with a finger and moving my eyes to control the same pointer.

Tracking the index finger

In hand mode, the script takes the index fingertip from each frame and maps a rectangle in the camera view to the screen. Using an inner rectangle means the pointer can reach the edges without the hand leaving the frame.

Small shifts in the detected fingertip can make the cursor jitter. The filter moves the cursor partway toward each new target. In the sample input trace, the cursor moves more steadily and lags slightly when the input changes direction.

Calibrating eye movement

The eye mode measures each iris relative to the corners of its eye. Measuring the position within the eye helps distinguish a change in gaze from the whole face shifting in the image.

The script records two reference points while the user looks toward opposite screen corners. It pauses movement if tracking is lost or the eyes close. Head motion and lighting still affect the result, so the preview shows where the cursor would go before desktop control is enabled.

Run the prototype

Run the project with Python 3.9 and a webcam. Press H for hand input or E for eye input. Use --video to try a local recording in preview. With a live camera, start with --move and press Space to enable desktop cursor control.
