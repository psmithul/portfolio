Finite Element Analysis of Beams and Frames

ME311 Finite Element Method · NITK team coursework · Nov 2026

For our finite element coursework, we solved static beam bending, free vibration, and plane-frame problems in MATLAB. We built matching models in ANSYS to check the results and see how they changed with the mesh.

Model setup

We wanted to trace the result from the element equations to the plotted displacement or mode shape. Before comparing the two programs, we matched the geometry, support conditions, and loads for each case.

Assembly and mesh convergence

In MATLAB, we mapped the element degrees of freedom into the global system and then applied the supports and loads. The plane-frame members start in their own axes, so we transformed them into global coordinates before assembly.

For the static cases, we compared displacements as we refined the mesh. The convergence curves showed how the discretisation affected the result. Assembling the equations ourselves made it easier to trace an unexpected displacement back to a support condition or a degree-of-freedom mapping.

For the static beam in ANSYS, the linear-element model gave a centre displacement of about −20.25 mm with two elements and −33.06 mm with 64 elements. The algebraic reference was −33.08 mm. That series showed how strongly the coarse mesh affected this particular result.

We kept the support and loading definitions the same while changing mesh density. That made the displacement comparison easier to interpret: if the centre result moved closer to the reference as the mesh was refined, we could tie the change to the discretisation in that model.

Free-vibration comparison

We used the mass and stiffness matrices to calculate natural frequencies and mode shapes. Keeping the span as a parameter let us run the same calculation for different lengths. For the 2 m case, we compared the first frequency and the corresponding deformation in ANSYS to check that both models described the same motion.
