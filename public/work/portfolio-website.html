Personal project

I built this site to keep my project write-ups, original figures, and notes in one place.

About, Projects, and Build Log are separate HTML pages that share one stylesheet.

How it changed

Earlier versions used an interactive 3D journey. I moved to a simpler layout so the original CAD, photos, and results could do more of the work. Older project links still point to the current write-ups.

How I publish

Earlier versions used Next.js and a private writing desk. I now edit posts and case studies as HTML, and a push to the main branch publishes them on Vercel. GitHub source.
