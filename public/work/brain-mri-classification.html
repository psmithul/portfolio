Brain MRI Classification

Python · Machine learning · 2021

We worked on classifying brain MRI images in Python. We prepared the images, trained a convolutional neural network, and used it to classify individual images. We presented the project at NITK EngiConnect, where our team placed second.

Preprocessing and augmentation

The Keras image generator resizes each grayscale image and scales its pixel values. During training, it applies small shifts and rotations to vary image placement and orientation while keeping the label fixed.

Validation and test images go through the same resizing and scaling. They skip the random transforms. For MRI data, I would keep all slices from the same person together when splitting the dataset so nearby slices cannot end up on both sides of the evaluation.

Training and classification

The network uses three convolution layers to learn image features and returns a score for each folder label. The prediction command loads the saved model and label order, prepares one image, and prints the scores.

I ran the training and prediction commands on abstract shapes to check the full pipeline. The plot records how loss and accuracy changed during that run. The project was an educational classifier. It has no clinical validation.

Run the classifier

Use Python 3.9 and TensorFlow 2.7. Run demo-data to generate the example images, train to fit and save the CNN, and predict to classify one image with the saved HDF5 model.
