Brain MRI Classification

Python · Machine learning · 2021

We worked on classifying brain MRI images in Python. We prepared the images, trained a convolutional neural network, and used it to classify individual images. We presented the project at NITK EngiConnect, where our team placed second.

Preprocessing and augmentation

I used the 2017 release of Jun Cheng’s dataset for the notebook. It contains 3,064 slices from 233 patients. I converted the MATLAB arrays to grayscale PNGs and kept all slices from the same patient in one split. The model trains on 165 patients, uses 34 for validation, and leaves 34 for testing.

The Keras image generator resizes each image to 96 × 96 and scales its pixel values. The training generator adds small shifts and rotations. The validation and test images keep their original orientation and placement.

Training and classification

The first CNN averaged each feature across the whole image. It reached 66.2% slice accuracy on the test split and missed all 92 meningioma slices. I kept the spatial layout of the features before the final layers and gave the less common classes more weight during training.

On the same split, the revised model classified 347 of 438 slices correctly, including 69 of the 92 meningioma slices. The matrix shows where the labels still got mixed up. This is a comparison on one public dataset. The project has no clinical validation.

Run the classifier

The notebook downloads the original Figshare files, prepares the images, trains the CNN, and runs a prediction on one held-out slice. The local download also supports Python 3.9 and TensorFlow 2.7.
