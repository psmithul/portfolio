## Static site

Edit the HTML and CSS under `public/`. Vercel serves that directory as-is. Keep navigation, local links, and the sitemap in sync when adding or moving pages.

## Portfolio publishing workflow

After completing requested portfolio updates, commit and push the changes, merge them into `main` after the required checks pass, and verify the Vercel production deployment. The user has authorized this workflow for future updates; do not ask again for these routine publishing steps.
